# 🚘 RAG Chat Assistant (DeepContext)

RAG-чат-ассистент для вопросов по документам с хранением эмбеддингов и семантическим поиском через векторную базу данных Milvus.

## 📌 Описание

Проект реализует архитектуру **Retrieval-Augmented Generation (RAG)** для работы с текстовыми документами.  
Документы разбиваются на чанки, преобразуются в эмбеддинги и сохраняются в Milvus, после чего для каждого пользовательского запроса выполняется быстрый семантический поиск релевантного контекста.

Найденные фрагменты передаются в LLM (GigaChat) для генерации ответа строго на основе исходных документов, что обеспечивает воспроизводимость и контроль источников.

## 🧠 Архитектура

1. Чтение и предобработка документов  
2. Генерация эмбеддингов текстовых чанков  
3. Сохранение и индексация в Milvus  
4. Семантический поиск релевантных фрагментов  
5. Генерация ответа с использованием LLM  

## 🗂 Структура проекта

- `main.py` — точка входа, запуск чат-ассистента  
- `llm.py` — взаимодействие с LLM (GigaChat)  
- `embeddings.py` — генерация эмбеддингов  
- `milvus_store.py` — работа с Milvus (сохранение и поиск векторов)  
- `utils.py` — вспомогательные функции  
- `dockerfile` — сборка контейнера приложения  
- `docker-compose.yml` — запуск Milvus и сервиса  
- `.env.example` — пример переменных окружения  
- `requirements.txt` — зависимости проекта  

## ⚙️ Переменные окружения

Перед запуском создайте файл `.env` на основе `.env.example` и укажите необходимые ключи доступа (LLM, Milvus и др.).

## 🚀 Запуск через Docker

Рекомендуемый способ запуска:

```bash
docker compose up --build
```
