# 😼 RAG Chat Assistant (DeepContext)

Простой RAG-чат-ассистент для ответов на вопросы по документам.

## 📌 Описание

Проект реализует базовую схему **Retrieval-Augmented Generation**: документы читаются, разбиваются на фрагменты, для них считаются эмбеддинги, после чего релевантные чанки находятся напрямую в коде и передаются в LLM для генерации ответа.

В этой версии **не используется Milvus** — retrieval реализован в `retrieval.py`, что делает проект максимально простым и наглядным.

## 🗂 Структура проекта

- `main.py` — точка входа, запуск чата  
- `llm.py` — работа с LLM (GigaChat)  
- `embeddings.py` — получение эмбеддингов  
- `retrieval.py` — поиск релевантных фрагментов  
- `utils.py` — вспомогательные функции  
- `requirements.txt` — зависимости  

## 🚀 Запуск

```bash
pip install -r requirements.txt
python main.py
```

## 🧠 Версии проекта
- `main` — версия без векторной базы данных, retrieval реализован напрямую в коде
- `milvus` — версия с хранением эмбеддингов и поиском релевантных документов через Milvus
